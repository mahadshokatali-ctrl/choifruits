# 🍊 FruitChoi – Restaurant Website

## 📌 Project Overview
FruitChoi is a modern and user-friendly restaurant website designed to showcase delicious food, display menu categories, and provide essential restaurant information. It features a clean layout, attractive orange-and-white colour scheme, and easy navigation to create a pleasant browsing experience.

## ✨ Features
- **Home Section:** Welcoming homepage with restaurant introduction.
- **About Section:** Information about the restaurant.
- **Menu Section:** Displays available food items in organized cards.
- **Menu Filters:** Allows users to filter menu items by category.
- **Contact Section:** Provides restaurant contact information.
- **Navigation Bar:** Easy navigation between website sections.
- **Logo & Branding:** Custom FruitChoi logo and website name.
- **Responsive Design:** Adapts to different screen sizes.

## 🛠️ Technologies Used
- HTML5 – Website structure.
- CSS3 – Styling and layout.
- JavaScript – Interactive menu filtering.

## 🎨 Design
- Primary Color: Orange (#f4a261)
- Secondary Color: Light Orange (#fff1e5)
- Background: White (#ffffff)
- Text Colors: Grey (#666666) and Dark Grey (#333333)
- Font: Arial, sans-serif.

1. Download or clone this repository.
